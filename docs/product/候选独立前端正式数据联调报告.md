## 三条真实查询闭环

问题文字由当前业务库的机构、指标和日期目录自动生成，未读取评测库。HTTP 实测结果如下：

| 类型 | 返回行数 | 推荐图表 | 数据库查询耗时 | 结果 |
|---|---:|---|---:|---|
| 单值 | 1 | 无需图表 | 1.277 ms | 成功 |
| 机构排名 | 13 | 柱状图 | 1.645 ms | 成功 |
| 趋势 | 486 | 折线图 | 3.943 ms | 成功 |

三条规则均使用命名参数，不把机构、指标、日期或结果写入 SQL 字符串；SQL 均经过既有 `SQLGlotSafetyChecker` 后才由只读执行器运行。

## 异常验证

- 正式数据库路径不存在时，`/ready` 返回 HTTP 503、`not_ready`、`database_ready=false`；
- 尚未支持的正式问题返回结构化 `UNSUPPORTED_QUESTION`，不生成 SQL；
- 前端网络错误、后端错误和结构化业务错误均显示可理解提示，不显示 Python 或数据库内部异常；
- 未添加任意来源 CORS，页面与 API 由同一服务提供。

## 已知限制

1. 当前只支持单值、机构排名和趋势三类确定性问法；其他四类展示契约仍保留，但尚未接通正式规则。
2. 历史会话使用浏览器 `localStorage`，可经刷新和服务重启恢复，但不能跨设备、多浏览器或多人共享。
3. `conversation_id` 已持续传递；真正的上下文省略理解仍需要后端多轮语义能力。
4. 权限、脱敏和审计字段未由后端提供时，前端只显示“暂未提供”，不会伪造。
5. 候选版尚未替换正式入口；发生问题时停止 8512 服务并启动原 Streamlit 页面即可回退。
