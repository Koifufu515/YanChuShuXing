## 三条真实查询闭环

问题文字由当前业务库的机构、指标和日期目录自动生成，未读取评测库。HTTP 实测结果如下：

| 类型 | 返回行数 | 推荐图表 | 数据库查询耗时 | 结果 |
|---|---:|---|---:|---|
| 单值 | 1 | 无需图表 | 1.277 ms | 成功 |
| 机构排名 | 13 | 柱状图 | 1.645 ms | 成功 |
| 趋势 | 486 | 折线图 | 3.943 ms | 成功 |

三条规则均使用命名参数，不把机构、指标、日期或结果写入 SQL 字符串；SQL 均经过既有 `SQLGlotSafetyChecker` 后才由只读执行器运行。

## 图表修复与字段边界

- 图表资源复用 `dashbord/dashbord/static/echarts.min.js` 的本地文件，复制前后 SHA-256 均为 `E84270BD0CD5BDF60FEFC26D00C2A391CB2E81F4D26A7A9EE16185A54773A3CF`；未下载新依赖，也没有 CORS 或 CDN 依赖。
- 通用适配器仅按 `metric_value`、`metric_unit`、`metric_name`、`institution_name`、`data_date` 五个字段名定位数据。浏览器审计故意打乱列顺序，结果仍正确。
- 单值只展示指标名和格式化后的数值/单位，例如 `41.70 亿元`，`chart_type=none` 时不生成伪柱状图。
- 排名图展示 13 家机构的完整名称，横向数值轴从 0 开始，带网格、单位和悬浮提示。
- 趋势图按日期排序并绘制全部 486 个点，不再截取前 12 行；横轴只保留 8 个均匀且不重复的日期标签，包含首末日期；纵轴根据真实范围留出边距，并正确处理负值和零值。
- 每次切换消息或历史会话时先销毁旧图表；窗口尺寸变化时统一调用 `resize`，避免多轮对话相互覆盖或残留。
- 后端未返回的数据来源、安全、脱敏和审计字段仍显示“暂未提供”，没有补造数据。

## 启动与回退

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_candidate_frontend.ps1 -GeneratorMode rule -Port 8512
```

访问 `http://127.0.0.1:8512/candidate`。当前验收服务已按此方式重启在 8512。需要回退时仅停止该进程，再按 README 启动现有 Streamlit 页面；两套入口没有相互覆盖。

## 已知限制

1. 当前只支持单值、机构排名和趋势三类确定性问法；其他四类展示契约仍保留，但尚未接通正式规则。
2. 历史会话使用浏览器 `localStorage`，可经刷新和服务重启恢复，但不能跨设备、多浏览器或多人共享。
3. `conversation_id` 已持续传递；真正的上下文省略理解仍需要后端多轮语义能力。
4. 权限、脱敏和审计字段未由后端提供时，前端只显示“暂未提供”，不会伪造。
5. 候选版尚未替换正式入口；发生问题时停止 8512 服务并启动原 Streamlit 页面即可回退。
