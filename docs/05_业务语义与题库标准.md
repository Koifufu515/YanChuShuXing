# 05号负责人：业务语义与题库标准

05号业务语义资产的唯一正式工作簿为：

[`docs/business_semantics/银行智能问数语义字典.xlsx`](business_semantics/银行智能问数语义字典.xlsx)

该字典仅依据官方21项基础指标、120道TRAIN题和当前已确认的公共规则整理。VAL与TST不用于新增指标、算子、业务概念、语言规则、Few-shot示例或专用Rule。

字典包含统一指标、查询算子、业务概念和语言解释四类结构化语义。当前业务概念状态统一为“待项目确认”；问题依赖待确认概念时，系统应返回“语义不明确”并指出待确认概念。

后端应读取审核后的结构化语义元数据完成口径映射，不应由LLM临时猜测指标定义、计算方向或评价标准。完整题库异常审核资产采用私有方式维护，公开仓库仅保留脱敏的异常类型与处理状态，不包含官方答案明细。
