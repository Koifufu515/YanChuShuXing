# Real 数据库使用说明

Real 是默认数据源。将官方工作簿放入 Git 忽略的 `data/private/official/` 后执行：

```bash
PYTHONPATH=. .venv/bin/python scripts/data/init_real_database.py --source <官方工作簿路径>
PYTHONPATH=. .venv/bin/python scripts/data/validate_real_database.py
PYTHONPATH=backend:. BANKINSIGHT_DATA_ENV=real .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
curl -s http://127.0.0.1:8000/ready
```

系统只信任 `active_release.json` 中的 `run_id` 和源摘要，并据此重建业务库与隔离评测库路径。设置 `BANKINSIGHT_DATA_ENV=demo` 才会显式启用 Demo；Real 缺失时不会自动降级。

`BANKINSIGHT_DB_PATH` 可用于受控覆盖，绝对路径直接使用，相对路径按项目根目录解析。正式数据库和评测数据库均不提交 Git。
